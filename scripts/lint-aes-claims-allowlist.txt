# lint-aes-claims-allowlist.txt — regex allowlist for lint-aes-claims.sh.
#
# One extended-regex per line. Lines matching any of these patterns are
# excluded from the "forbidden AES claim" grep. Blank lines and lines
# starting with '#' are treated as comments and ignored by the linter.
#
# Membership policy: each entry must correspond to prose that
# LEGITIMATELY names the forbidden strings in order to say "we do NOT
# do this" — an ADR §Locked Decisions clause, the release-gate story
# that defines the guard, the PRD §Non-Goals row, the coding-standards
# "no cryptographic claims" rule, or the readiness-checklist row that
# lists AES re-introduction as a fail condition. Marketing prose that
# actually claims AES / secure storage is NOT permissible and must be
# scrubbed instead of allowlisted.
#
# The linter runs `grep -REni` and pipes matches through
# `grep -Evf <this-file>`, so patterns are extended-regex, case
# insensitive, and matched against grep's `<path>:<lineno>:<content>`
# output shape.
