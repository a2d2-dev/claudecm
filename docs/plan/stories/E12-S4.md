# E12-S4 — Homebrew tap distribution plan

**User story.**
As a macOS user, I want claudecm installable through Homebrew after v1.0.0 ships, so I can install and upgrade it through my normal package manager.

**Acceptance criteria.**
- The plan identifies the Homebrew tap repository, formula name, artifact URL pattern, checksum source, license, homepage, and version metadata.
- Formula updates are tied to GitHub Release artifacts produced by E12-S3, not locally built binaries.
- Install smoke includes `brew install`, `claudecm version`, and a no-write read-only command such as `claudecm --help`.
- Upgrade smoke covers `brew upgrade` from a prior version when available.
- Rollback guidance covers reverting a bad formula update and communicating the known-good version.
- The formula does not add telemetry, services, background daemons, shell prompt integration, or cloud behavior.

**PRD/architecture refs.** ADR-0002 E12; E12-S2; E12-S3.

**Test plan.**
- Happy: formula installs release artifact, checksum matches, `claudecm version` reports the tag.
- Edge: checksum mismatch blocks install; missing artifact URL blocks formula update before merge.

**No fallback writes.** N/A for planning; package installation writes are Homebrew-managed, not claudecm tool-config writes.

**Complexity.** M.

**Dependencies.** E12-S2, E12-S3.
