# E12-S2 — GoReleaser config plan

**User story.**
As a claudecm maintainer, I want a GoReleaser plan for repeatable multi-platform artifacts, so release builds produce archives, checksums, and changelog output without hand-packaging binaries.

**Acceptance criteria.**
- The plan covers supported OS/arch targets, archive naming, binary name, checksum generation, changelog generation, and snapshot vs release behavior.
- GoReleaser ldflags inject the version metadata defined by E12-S1.
- The plan includes a `goreleaser check` / dry-run validation step before tagging or publishing.
- Artifacts exclude local-only files and include only the binary plus required license/readme assets.
- The plan records the SBOM/provenance decision for v1.0.0 and how to add it later if deferred.
- The plan does not implement package-manager manifests directly inside this story; Homebrew/Scoop are tracked by E12-S4/E12-S5.

**PRD/architecture refs.** ADR-0002 E12; Architecture tech stack release row; Architecture source-tree release files.

**Test plan.**
- Happy: `goreleaser check` passes and snapshot dry-run produces archives/checksums for the target matrix.
- Edge: missing ldflag variable or unsupported GOOS/GOARCH fails validation before publish.

**No fallback writes.** N/A for planning; implementation story must not publish artifacts during dry-run.

**Complexity.** M.

**Dependencies.** E12-S1.
