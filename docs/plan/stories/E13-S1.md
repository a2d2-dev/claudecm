# E13-S1 — Local redaction + heuristic blob extractor

**User story.**
As a claudecm user pasting a messy blob (provider onboarding text, an `export` snippet, a chat log), I want claudecm to locally detect the base URL / API key / model and produce both the extracted fields and a secret-free desensitized copy of my text, so later stories can build a profile draft without any secret ever needing to leave my machine.

**Acceptance criteria.**
- A new package (`internal/blobparse`) exposes a pure function that takes arbitrary text and returns: extracted core fields (`base_url`, `api_key`, `model`, `small_fast_model`, `provider` where inferable), a map of captured secrets, and a **desensitized** copy of the input.
- Extraction is heuristic and local: recognizes `KEY=VALUE`, shell `export KEY=VALUE`, JSON/YAML `"key": "value"`, and common label forms (`API Key: ...`, `Base URL: ...`) for the Anthropic/Codex field vocabulary.
- Secret detection covers `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `OPENAI_API_KEY`, and generic `sk-`/token-shaped values; every detected secret is replaced by a stable placeholder in the desensitized copy.
- **Strip-on-doubt:** a token that looks secret-shaped but cannot be safely mapped to a placeholder is removed from the desensitized copy entirely rather than passed through. No secret-shaped token survives desensitization.
- Pure function, no I/O, no network, deterministic; provider inference (if any) never claims official support.

**PRD/architecture refs.** ADR-0003 Locked Decisions 1 & 6; PRD FR-1, NFR-S1, NFR-S8; Architecture §2.1.

**Test plan.**
- Happy: an `export ANTHROPIC_BASE_URL=... ANTHROPIC_AUTH_TOKEN=sk-...` blob → base_url + key extracted; desensitized copy contains a placeholder, not the key.
- Happy: a prose blob (`Base URL: https://... , API Key: sk-...`) → fields extracted.
- Edge: blob with a bare `sk-xxxx` and no label → captured as a secret; desensitized copy has no `sk-` token.
- Edge: blob with no recognizable fields → empty extraction, no panic, desensitized copy equals input (nothing secret-shaped to strip).
- Property: for a corpus of blobs, assert no secret-shaped token appears in any desensitized output.

**No fallback writes.** N/A — pure library; no disk writes.

**Complexity.** M.

**Dependencies.** E1-S1, E6-S3.
